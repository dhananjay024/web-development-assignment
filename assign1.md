When we type URL and press enter.Then following steps happens:
1 . Browser reads the website address.
2 . Now, DNS server finds the IP address of the website by translating domain name of website.
(eg. abc.com).
3 . After it Browser connects to website's server.
4 . The server sends the website's files. such as: html,java,c.
5 . Finally, the browser reads the files and displays the webpage on screen.
